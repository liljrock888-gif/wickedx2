# Wickedx2 website

Live site: https://liljrock888-gif.github.io/wickedx2/

## How to update the site (no coding needed)

Everything you'd want to change is in **`content.js`**.

1. Open `content.js` here on GitHub and click the ✏️ (pencil) icon.
2. Make your change:
   - **New video/Short:** add a line at the top of the `VIDEOS` list, like
     `{ link: "https://youtube.com/shorts/AbCdEfGhIjK", title: "My new video" },`
   - **About text, tagline, email, socials:** edit the lines in `CHANNEL`.
   - **Merch:** add products to `MERCH` (instructions are in the file).
3. Click **Commit changes**. The site updates in about a minute.

The "Latest Upload" player updates by itself whenever you upload, so you never need to edit it.
